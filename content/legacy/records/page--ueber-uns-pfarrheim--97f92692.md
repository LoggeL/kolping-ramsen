# Die Geschichte des katholischen Pfarrheims

## ( Kloster „Ramosa“ 1146 – 1494 )

### Zehntscheune des Klosters

| 1494 – 1793 | Bischöfliches Klostergut ( Worms ) |
| --- | --- |
|  | Tagungsort des „Stumpfwaldgerichts“( Neunmärkerei )Ausgangs- und Endpunkt der Grenzumgänge |
| 1793 | Enteignung durch den franz, Staat |
| 1793 – 1814 | Französische Staatsdomäne |
| 1814 – 1828 | Eigentum des Königreiches Bayern |
| 1828 | Der Klosterbesitz wird an Private versteigertDas Gebäude wechselt mehrmals den BesitzerMitte des 19. Jahrh. wird im Innern eine Kapelle errichtet |
| 1894 | Das Gebäude geht als Vermächtnis an die kath.Kultusgemeinde |
| 1907 | Der „Elisabethenverein“ übernimmt das Haus |
| 1912 | Schwesternhaus der „Armen Schulschwestern Speyer“Krankenpflegestation,Kinderbewahranstalt,Handarbeitsschule |
| 1977 | Die letzten Schwestern verlassen Ramsen |
| 1980 | Einweihung des „Pfarrheims“ nach Umbau und Renovierungin Eigenleistung durch die Kolpingsfamilie Ramsen |
